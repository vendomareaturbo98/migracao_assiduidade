# Frontend — React

## Requisitos
- Node.js LTS
- npm

## Instalar dependências
Na pasta `nova-versao/frontend`:

```bash
npm install
```

## Executar em desenvolvimento
Inicie a API Java em outro terminal e depois execute:

```bash
npm run dev
```

Acesse `http://localhost:5173`. A variável opcional `VITE_API_URL` define o endereço da API; por padrão é `http://localhost:8080`.

## Gerar versão de produção
```bash
npm run build
npm run preview
```
