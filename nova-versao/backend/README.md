# Backend — Spring Boot

## Requisitos
- JDK 21
- Maven 3.9+

## Executar
Na pasta `nova-versao/backend`:

```bash
mvn spring-boot:run
```

Verificação: `GET http://localhost:8080/api/health`.

A API ainda não está conectada ao banco. Não configure aqui a URL do Supabase ou do banco de produção nesta etapa.
